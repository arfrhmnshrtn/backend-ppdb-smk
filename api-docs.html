API PPDB SMK

Dokumentasi API PPDB SMK

Selamat datang di dokumentasi resmi API Pendaftaran Peserta Didik Baru (PPDB) SMK. API ini dibangun dengan framework NestJS dan dirancang sedemikian rupa agar mudah diintegrasikan dengan aplikasi Frontend Anda.

Base URL

Semua endpoint API pada dokumentasi ini merujuk secara relatif pada URL server utama Anda, contohnya: http://localhost:3000.

Panduan Autentikasi (Authorization)

Beberapa endpoint dalam API ini bersifat protected (dilindungi) dan memerlukan otentikasi menggunakan metode JWT (JSON Web Token).

Bagaimana cara kerjanya?

  1. Kirim request login ke endpoint /auth/login (untuk siswa) atau /auth/login-admin (untuk admin).
  2. Jika berhasil, server akan mengembalikan data beserta properti token.
  3. Sematkan token tersebut pada HTTP Headers di setiap request yang membutuhkan otorisasi.

Format Header Request

Authorization: Bearer <token_anda_disini>

Penting

Hak akses (Role) dibedakan menjadi USER (siswa) dan ADMIN. Beberapa endpoint tertentu seperti /berkas/all-berkas akan secara spesifik menolak request jika token yang digunakan bukan milik Admin (mengembalikan status 403 Forbidden).

Authentication

POST

/auth/register

Public

Mendaftarkan akun baru untuk pendaftar/siswa.

Request Body (application/json)

Parameter Type Keterangan
name String Nama lengkap pendaftar (wajib)
email String Alamat email unik (wajib)
password String Kata sandi akun (wajib)

Response 201 Created 

{
  "status": true,
  "message": "Pendaftaran berhasil"
}
POST

/auth/login

Public

Masuk ke akun siswa dan mendapatkan JWT Token.

Request Body (application/json)

{
  "email": "siswa@example.com",
  "password": "password123"
}

Response 200 OK 

{
  "status": true,
  "message": "Login berhasil",
  "data": {
    "id": 1,
    "name": "Nama Siswa",
    "email": "siswa@example.com",
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  }
}
POST

/auth/register-admin

Public

Mendaftarkan akun baru yang secara otomatis diberikan role ADMIN.

Request parameter dan format response identik dengan endpoint /auth/register biasa.

POST

/auth/login-admin

Public

Masuk ke sistem khusus untuk akun ber-role ADMIN. Akan mengembalikan Error 401 jika login menggunakan akun siswa.

Request parameter dan format response identik dengan endpoint /auth/login biasa.

Upload Berkas

POST

/berkas/upload

Auth Required

Menyimpan data pendaftaran siswa dan mengupload file dokumen pendukung secara bersamaan.

Request Form Data (multipart/form-data)

Key Type Keterangan
nama Text Nama lengkap siswa
no_hp Text Nomor Handphone yang bisa dihubungi
nisn Text Nomor Induk Siswa Nasional
asal_sekolah Text Nama sekolah sebelumnya
alamat Text Alamat domisili lengkap
jurusan Text/Enum Jurusan yang dipilih (sesuai enum Prisma)
Attachment Files (Max 5MB per file, Format: PDF/JPG/PNG)
surat_keterangan_lulus File Scan Surat Keterangan Lulus (SKL)
raport File Scan Raport Sekolah
ktp_ayah File Scan KTP Ayah
ktp_ibu File Scan KTP Ibu
kartu_keluarga File Scan Kartu Keluarga (KK)
akta_kelahiran File Scan Akta Kelahiran
pas_foto File Pas Foto Formal
sptjm File Surat Pernyataan Tanggung Jawab Mutlak
kip File Kartu Indonesia Pintar (Opsional)
paiagam File Piagam Penghargaan (Opsional)
sk_osis File SK Pengurus OSIS (Opsional)
sk_pramuka File SK Pramuka (Opsional)

Response 201 Created 

{
  "status": true,
  "message": "Berkas berhasil diupload",
  "metadata": {
    "statusCode": 201
  }
}
PATCH

/berkas/edit

Auth Required

Memperbarui data diri siswa atau mengupload ulang berkas yang salah/ditolak oleh admin.

Persyaratan Khusus Endpoint Edit

API akan menolak perubahan (Error 400 Bad Request) apabila TIDAK ADA SATU PUN dokumen milik siswa yang berstatus REVISI.

Request Form Data (multipart/form-data)

Parameter sama dengan endpoint /berkas/upload. Semua field bersifat opsional (partial update). Anda cukup mengirimkan data atau file yang ingin diubah saja.

Response 200 OK 

{
  "status": true,
  "message": "Berkas berhasil diupdate",
  "metadata": {
    "statusCode": 200
  }
}

Users

GET

/users

Public

Melihat data diri ringkas daftar siswa yang sudah terdaftar. Dapat difilter berdasarkan jurusan yang dipilih.
