JWT Authentication

Hampir seluruh endpoint dalam sistem dilindungi menggunakan token JWT (JSON Web Token). Untuk berinteraksi dengan API yang diamankan, sertakan token ke dalam header HTTP request:

HTTP Header Example 
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJzdWIiOjEsImVtYWlsIjoiaGFyeUBleGFtcGxlLmNvbSIsInJvbGUiOiJVU0VSIn0...
Payload JWT Structure 
{
  "sub": 1, // User / Admin ID
  "email": "haris@example.com",
  "role": "USER" // Nilai: "USER" atau "ADMIN"
}

PORTAL CALON SISWA (USER)

Kumpulan API yang diakses oleh calon siswa untuk pendaftaran, manajemen berkas, dan kartu ujian.

POST /auth/register
PUBLIC

Deskripsi

Pendaftaran akun baru untuk calon peserta didik baru (Siswa).

Request Body

Field Type Requirement Validasi
name string Required IsString(), IsNotEmpty()
email string Required IsString(), IsNotEmpty(), Email
password string Required IsString(), IsNotEmpty()
Payload JSON 
{
  "name": "Haris Setiawan",
  "email": "haris@example.com",
  "password": "rahasia123"
}
POST /auth/login
PUBLIC

Deskripsi

Login untuk Calon Siswa guna mendapatkan token akses JWT. Hanya menerima user dengan role USER.

{
  "status": true,
  "message": "Login berhasil",
  "data": {
    "id": 1,
    "name": "Haris Setiawan",
    "email": "haris@example.com",
    "token": "eyJhbGciOiJIUz..."
  }
}
POST /berkas/upload
JWT AUTH ROLE: USER

Deskripsi

Menyimpan biodata pendaftar sekaligus berkas fisik. Menggunakan format payload multipart/form-data.

Request Body (Form Fields)

Field Type Requirement
nama, no_hp, nisn, asal_sekolah, akreditasi_sekolah, alamat string Required
jurusan Enum (Jurusan) Required (contoh: TKJ, RPL, AKL)

File Fields (Max 5MB per file, PDF/JPG/PNG)

surat_keterangan_lulus raport ktp_ayah ktp_ibu kartu_keluarga akta_kelahiran pas_foto sptjm
cURL Upload 
curl -X POST http://localhost:3000/api/berkas/upload \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: multipart/form-data" \
  -F "nama=Haris" -F "nisn=00223" -F "jurusan=RPL" \
  -F "raport=@/path/to/raport.pdf"
PATCH /berkas/edit
JWT AUTH ROLE: USER

Digunakan untuk memperbarui berkas yang berstatus REVISI atau REJECTED, atau merubah biodata pendaftaran.

GET /berkas/all-berkas
JWT AUTH ROLE: USER

Menampilkan status verifikasi dan tautan berkas yang telah dikirim oleh siswa yang sedang login.

GET /cards/me
JWT AUTH ROLE: USER

Melihat detail kartu peserta ujian pendaftaran miliknya, seperti tanggal ujian, jam, dan lokasi ruangan.

{
  "no_daftar": "PPDB-2026-0001",
  "tanggal_test": "2026-06-15",
  "jam_test": "08:00 - 10:00",
  "lokasi_test": "Laboratorium TKJ 1"
}
GET /cards/me/download
JWT AUTH ROLE: USER

Mengunduh file PDF Kartu Ujian pendaftaran secara dinamis.

GET /users/registration-status
JWT AUTH ROLE: USER

Mengetahui status akhir verifikasi berkas pendaftaran (VERIFIED / REVISI / REJECTED) beserta catatan detail dari Panitia Admin.

{
  "success": true,
  "data": {
    "verification_status": "REVISI",
    "documents_need_revision": [
      {
        "id": "doc-123",
        "type": "raport",
        "keterangan": "Nilai semester 3 salah input"
      }
    ]
  }
}

PORTAL PANITIA (ADMIN)

Kumpulan API pengelolaan pendaftaran, validasi berkas fisik, scoring rata-rata rapor, dan penjadwalan ujian seleksi.

POST /auth/register-admin
PUBLIC

Pendaftaran akun panitia administrator baru dengan hak akses pengolahan data.

POST /auth/login-admin
PUBLIC

Autentikasi khusus user Admin. Menghasilkan JWT token dengan role ADMIN.

GET /users
PUBLIC/ADMIN

Melihat daftar seluruh data siswa pendaftar. Mendukung pencarian berdasar filter jurusan.

Query Parameter Type Keterangan
jurusan string Optional. Contoh: TKJ atau RPL. 
{
  "status": true,
  "data": [
    {
      "idUser": 2,
      "nama": "Ahmad Wijaya",
      "jurusan": "RPL"
    }
  ]
}
PATCH /validations/documents/:id
JWT AUTH ROLE: ADMIN

Memvalidasi satu jenis dokumen fisik pendaftar (misal: pas foto, rapor, akta) berdasarkan ID dokumen.

Body Field Type Validasi
status Enum VERIFIED, REVISI, REJECTED
keterangan string Wajib jika status REVISI/REJECTED. 
{
  "status": "REVISI",
  "keterangan": "Dokumen pas foto blur, mohon upload ulang"
}
PATCH /validations/students/:studentId/documents
JWT AUTH ROLE: ADMIN

Memvalidasi banyak berkas sekaligus milik calon siswa tertentu (bulk verification) dalam satu request.

{
  "documents": [
    {
      "document_id": "doc-uuid-a",
      "status": "VERIFIED",
      "keterangan": null
    },
    {
      "document_id": "doc-uuid-b",
      "status": "REVISI",
      "keterangan": "KTP Buram"
    }
  ]
}
POST /rapor-scores
JWT AUTH ROLE: ADMIN

Menyimpan data nilai rapor semester 1-5 dan poin prestasi. Sistem otomatis mengalkulasi nilai rata-rata dan bobot akreditasi sekolah asal.

Field Type Validasi
id_student integer IsInt()
semester_1 s/d 5 float Min(0), Max(100)
prestasi integer Min(0), Max(10) 
{
  "id_student": 5,
  "semester_1": 88.5,
  "semester_2": 90.0,
  "semester_3": 85.0,
  "semester_4": 87.5,
  "semester_5": 91.2,
  "prestasi": 2
}
GET /rapor-scores
JWT AUTH ROLE: ADMIN

Menampilkan peringkat skor akhir rapor seluruh pendaftar secara menurun (descending) untuk proses seleksi kelulusan.

GET /rapor-scores/:id
JWT AUTH ROLE: ADMIN

Mengambil detail nilai rapor beserta bobot akhir milik satu siswa berdasarkan ID rapor.

PATCH /rapor-scores/:id
JWT AUTH ROLE: ADMIN

Merubah sebagian nilai semester atau prestasi. Rata-rata dan skor akhir otomatis dihitung ulang.

DELETE /rapor-scores/:id
JWT AUTH ROLE: ADMIN

Menghapus data rapor pendaftar dari sistem database.

POST /cards/test-schedules
JWT AUTH ROLE: ADMIN

Membuat sesi / jadwal ujian test akademik untuk calon siswa pendaftar.

Field Type Keterangan
tanggal_test string (Date) IsDateString()
jam_test string Contoh: "08:00 - 10:00"
lokasi_test string Contoh: "Lab RPL" 
{
  "tanggal_test": "2026-06-15T00:00:00.000Z",
  "jam_test": "08:00 - 10:00",
  "lokasi_test": "Lab Komputer Utama"
}
GET /cards/test-schedules
JWT AUTH ROLE: ADMIN

Menampilkan seluruh daftar slot jadwal ujian yang tersedia.

PATCH /cards/test-schedules/:id
JWT AUTH ROLE: ADMIN

Memperbarui info tanggal, jam, atau tempat dari suatu sesi ujian berdasarkan ID.

DELETE /cards/test-schedules/:id
JWT AUTH ROLE: ADMIN

Menghapus sesi jadwal ujian pendaftaran tertentu.
